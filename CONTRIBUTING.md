# Contributing

Terima kasih telah membantu! Kirim issue atau pull request berisi konteks, cara reproduksi, dan contoh output **yang sudah disamarkan** (hapus nomor seri dan data sensitif).

- Perubahan IOC harus menyertakan URL sumber intelijen yang dapat diverifikasi.
- Jangan sertakan APK malware, dump kredensial, data banking, hasil scan privat, atau informasi rahasia.
- Pertahankan sifat read-only terhadap perangkat Android. Operasi yang mengubah perangkat tidak boleh diperkenalkan tanpa peninjauan eksplisit.
- Uji `python3 -m unittest discover -s tests -v` sebelum mengirim pull request.
