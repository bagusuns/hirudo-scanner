# Security Policy

Jangan unggah laporan scan nyata atau sampel malware ke issue publik. Untuk kerentanan keamanan pada script ini, laporkan secara privat melalui fitur **GitHub Private vulnerability reporting** apabila sudah diaktifkan oleh pemilik repo. Jika belum tersedia, buka issue tanpa detail eksploitasi atau data sensitif untuk meminta kanal komunikasi privat.

Scanner dirancang membaca metadata/APK dari perangkat melalui ADB; pengguna bertanggung jawab memastikan otorisasi pemeriksaan.
